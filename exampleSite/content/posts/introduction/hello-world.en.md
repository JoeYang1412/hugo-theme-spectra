## Welcome

This is a demo post for the **Spectra** Hugo theme. Spectra blends a "Light Sci-Fi × Anime Fusion" aesthetic — keeping reading comfortable while adding tech-inspired visual details.

## Key Features

- **Dark / Light Mode**: Follows system preference, manual toggle available
- **Parallax Banner**: Floating particles with L-bracket corner decorations
- **Scroll Entrance Animations**: Cards fade in with blur-to-sharp transitions
- **Code Copy Button**: One-click copy with auto language label
- **KaTeX Math Support**: Inline and block formulas
- **Table of Contents**: Sticky sidebar on desktop, collapsible on mobile
- **Multilingual (i18n)**: Traditional Chinese × English

## Quick Start

```toml
# hugo.toml
baseURL = 'https://your-site.github.io/'
theme   = 'hugo-theme-spectra'
```

Create your first post:

```bash
hugo new content content/posts/my-first-post.md
```

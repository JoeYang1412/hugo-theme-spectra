## 歡迎

這是 **Spectra** Hugo 主題的示範文章。Spectra 以「Light Sci-Fi × Anime Fusion」為設計方向，在保持閱讀舒適度的前提下，融入科技感的視覺元素。

## 主要功能

- **Dark / Light 模式**：跟隨系統設定，也可手動切換
- **視差 Banner**：含浮動粒子與 L 形角括號裝飾
- **滾動進場動畫**：卡片逐一淡入，帶有模糊到清晰的過渡
- **程式碼複製按鈕**：一鍵複製，自動顯示語言標籤
- **KaTeX 數學支援**：行內與區塊公式皆可
- **文章目錄（TOC）**：桌面側邊固定，行動裝置收合
- **多語言（i18n）**：繁體中文、English

## 快速開始

```toml
# hugo.toml
baseURL = 'https://your-site.github.io/'
theme   = 'hugo-theme-spectra'
```

建立第一篇文章：

```bash
hugo new content content/posts/my-first-post.md
```

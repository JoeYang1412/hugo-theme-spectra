## 標題層級

這篇文章用了 `h2`、`h3`、`h4` 三層標題。右邊的目錄（桌面版）或上方的摺疊目錄（手機版）會自動抓這些標題。

### 這是 H3

#### 這是 H4

一般來說三層就夠了。層級太多反而讓結構變複雜。

## 文字格式

基本的文字樣式：

- **粗體** — 用 `**文字**`
- *斜體* — 用 `*文字*`
- ~~刪除線~~ — 用 `~~文字~~`
- `行內程式碼` — 用反引號包起來
- [超連結](https://example.com) — 用 `[文字](網址)`

這些可以混著用，像是 **粗體裡面放 `程式碼`** 或是 *斜體加上[連結](https://example.com)*。

- 第一項

  - 巢狀項目 B
    - 再往下一層也行

2. 新增一個 Markdown 檔案
3. 開始寫
4. 存檔
5. 部署

## 表格

表格在技術文章裡很常用。Spectra 的表格會自動套用邊框和斑馬紋底色。

| 快捷鍵 | 功能 | 平台 |
|--------|------|------|
| `Ctrl+S` | 儲存 | Windows / Linux |
| `Cmd+S` | 儲存 | macOS |
| `Ctrl+Shift+P` | 命令面板 | VS Code |
| `Ctrl+/` | 切換註解 | 大多數編輯器 |

靠左、靠右、置中對齊：

| 左對齊 | 置中 | 右對齊 |
|:-------|:----:|-------:|
| 蘋果 | 100g | $1.50 |
| 香蕉 | 120g | $0.75 |
| 橘子 | 150g | $2.00 |

## 水平線

三個減號就是一條水平線：

---

用來分隔不同主題的段落。

## 巢狀引言與清單

引言裡也可以放清單：

> 好的技術文章通常有這些特徵：
>
> - 開頭就講重點
> - 有實際的範例
> - 段落不要太長
> - 最後有總結

## 腳註

Markdown 支援腳註[^1]。滑鼠移上去或點擊，可以看到對應的註解。

[^1]: 這是腳註的內容。腳註會出現在文章最下面。

## 定義清單

HTML
: 超文本標記語言，網頁的骨架。

CSS
: 階層式樣式表，負責網頁的外觀。

JavaScript
: 讓網頁動起來的程式語言。

---

以上就是 Spectra 支援的主要 Markdown 元素。寫文章的時候不用特別記語法，多寫幾次就熟了。
